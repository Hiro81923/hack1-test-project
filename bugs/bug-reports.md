## BUG-01
- **Название:** Заявка не переходит автоматически на главную страницу специалиста
- **Связанный тест-кейс:** SM-06
- **Модуль:** Request
- **Severity:** Critical
- **Priority:** High
- **Статус:** Open

### Предусловия
- Пользователь залогинен
- Открыто меню создания обращения

### Шаги воспроизведения
1. Создать обращение (С валидными данными)
2. Нажать **Создать обращение**
3. Нажать **Отправить на анализ**

### Ожидаемый результат
- Заявка создана
- Заявка автоматически перенесена на главную страницу специалиста

### Фактический результат
- Заявка существует в базе данных
- Заявка не перенесена на главную страницу
